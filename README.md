# 从零实现 LLM 权重量化:闭式误差预测、GPTQ 与注水式混合精度

本项目在自己的仓库里完成一条完整的量化链路:确定性高熵语料、从头训练 1.82M 参数语言模型、校准 Hessian、RTN 与 GPTQ 两种量化器(int8/4/3/2)、fake-quant 评测,以及一套可检验的误差理论。不依赖 transformers、不联网、无 GPU:README 里所有数字由仓库代码在单机 CPU 上产出。

GPTQ 本身是已知方法(Frantar et al., OPTQ/GPTQ, ICLR 2023),本项目从零复现其核心算法并如实标注出处。项目的自有贡献是围绕它的三条理论分析与一个分配算法,全部给出实测验证。

## 四条命题与实测结果

| | 命题 | 结果 |
|---|---|---|
| T1 | 均匀舍入方差 Δ²/12(高 bit 极限) | 200 万样本模拟,相对偏差 < 1% |
| T2 | 层重构误差闭式预测 `E[dᵀHd] = Σ_r v_r·tr(H) + Σ_r b_r²·1ᵀH1`(方差 + 舍入偏差交叉项,逐行 1-D 数值积分处理截断) | 3-bit 最差偏差 22.6%,4-bit 12.1%;**2-bit 失效(3-6×)**,失效机制被对齐放大因子 κ 实测定量解释(均值 16.7,最大 34.1) |
| T3 | GPTQ 二阶代理恒等式 `Σᵢ(w−q)²/U[i,i]² = ‖(W−Q)H^{1/2}‖²` 与 GPTQ ≤ RTN | 恒等式相对误差 6.85e-08;全部 16 层 × 3 个 bit 宽度上 GPTQ 实测误差 ≤ RTN;总重构误差与 ΔCE 的相关 0.946 |
| T4 | 注水式混合精度:在给定显存预算下最小化总重构误差 | RTN 在 2.5 bit/权重下把 uniform-2 的损失 +1.158 收回到 +0.659(43%);GPTQ 分配达到 −0.0000(完全无损),uniform-2 为 +0.0053 |

2-bit 上最直观的一条:RTN +1.158 → GPTQ +0.005,**损失降为 1/217**。

## 系统

- 语料:确定性高熵配置日志语言(`lmlab/data.py` 的 hard 变体),9,000 行、154k 字符、36 词表,数值范围与行类型都 比 easy 版本宽,模型被推到容量边界——这是量化的关键设计:在宽松语料上训练的模型对权重噪声过于鲁棒,整个 2-4 bit 前沿都没有信号(实测教训:第一版 easy 语料上 per-channel 3-bit 的 ΔCE ≈ 0,方法对比失去意义)。
- 模型:d = 192,4 层,4 头,d_ff = 768,1,820,544 参数,val CE 0.929,800 步 Adam 约 4 CPU 分钟;基准评测 CE 0.9386(perplexity 2.56)。
- 量化对象:block 内全部 16 个 nn.Linear(qkv、attention out、mlp 两层)。lm_head 与 token embedding 绑定,不量化,如实写明。
- 全部实现为 fake-quant(反量化后用普通 matmul 前向),这是 PTQ 研究的标准评测协议;本项目不包含 int4/int8 kernel。

## 评测结果

### E1:RTN 前沿(bits × 粒度,ΔCE 单位 nats/token)

| bits | per-tensor | per-channel |
|---|---|---|
| 2 | +6.427(ppl 1581) | +1.158 |
| 3 | +0.289 | +0.019 |
| 4 | +0.012 | +0.0015 |
| 8 | +0.0001 | +0.0001 |

### E2:方法对比(per-channel)

| bits | RTN | RTN+clip | GPTQ | GPTQ+clip |
|---|---|---|---|---|
| 2 | +1.158 | +0.064 | **+0.005** | +0.015 |
| 3 | +0.019 | +0.008 | **−0.000** | −0.000 |
| 4 | +0.0015 | +0.0005 | +0.0001 | +0.0005 |

两处如实报告的反直觉结果:MSE 最优截断搜索让 RTN 在 2-bit 上改善 18 倍(+1.158 → +0.064),但与 GPTQ 组合后反而略差(+0.015 vs +0.005)——两种误差再分配机制重叠,截断改变了 GPTQ 依赖的权重分布形态。

### E3:理论与实测的对账

- 闭式预测(T2)在 3/4-bit 上最差偏差 22.6%/12.1%,逐层 96 个测量点与 `results_quant/03_parity.tsv` 一一对应。
- **2-bit 失效与 κ**:各向同性预测假设舍入误差方向随机,但 2-bit 时每个权重只有 {-1,0,1}×Δ 三种取值,小幅值权重直接舍到零、误差等于权重本身,误差集中在行内小坐标子空间;同时训练出的权重行与输入协方差的 top 特征空间对齐(对齐放大因子 κ = wᵀHw/(‖w‖²·tr(H)/in),16 层均值 16.7,最大 34.1),trace(H) 按全体特征方向平均,因此系统性低估 3-6×。方向性预测(误差 ∝ 权重方向)同样不对——真实误差方向是行内小坐标子空间。结论:2-bit 没有便宜的闭式预测,混合精度分配改用校准集上的实测误差表,这是方法论上诚实的处理。
- GPTQ 代理恒等式相对误差 6.85e-08,是整个 GPTQ 实现正确性的强断言。

### E4:注水式混合精度

预算 2.5 bit/权重(比 uniform-3 少 17% 显存,比 uniform-2 多 0.5):

| 方法 | uniform-2 | 分配(2.5bpw) | uniform-3 |
|---|---|---|---|
| RTN | +1.158 | **+0.659** | +0.019 |
| GPTQ | +0.0053 | **−0.0000** | −0.0002 |

分配器 = 贪心边际 + 交换局部搜索(纯贪心会留下用不掉的内存碎片,实测输给暴力搜索 9%,交换搜索在测试中小规模情形与暴力最优一致)。成本表用校准集上的实测重构误差,RTN 版分配把注意力的 out 层提到 4 bit、mlp 压到 2 bit;GPTQ 版在同样预算下做到完全无损。

## 复现

```bash
pip install -r requirements.txt
python tests_quant.py -v                                       # 17 条断言
python -m lmlab.train --force --corpus hard --d-model 192 --n-layers 4 --suffix q
python experiments_quant.py                                    # 约 1 CPU 分钟
python experiments_quant.py --seed 7 --out results_quant_seed7 # 复现
```

全链路确定性:语料、初始化、校准窗口、评测窗口全部固定种子,重跑逐字节一致(训练一次约 4 分钟,之后实验直接读 checkpoint)。

## 如实写明的边界

- 字符级 36 词表、合成语料、1.82M 参数:理论结构与结论可迁移,绝对数字不能对应 7B 级模型。
- 2-bit 没有精确闭式预测:失效机制(小坐标主导 + κ 对齐放大)被定量化,但精确预测只能靠校准集实测,这是结论而不是缺陷。
- RTN+clip 的闭式预测一般(0.5-0.6 的对数偏差):截断后误差分布偏离高斯模型,未做更精细的建模。
- fake-quant 协议:不包含真整数 kernel 与实际显存/带宽测量。
- KKT 边际比在使用实测成本表时只是描述性参考(实测表非平滑),分配器的最优性由小规模暴力搜索对照验证。
