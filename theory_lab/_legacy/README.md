# AI4S 项目代码库

基于生成式模型的分布依赖随机过程高效采样实验。完整可复现。

## 项目结构

```
ai4s/
  birthdeath.py    生灭过程模型与精确不变测度（含分布依赖项，谱隙）
  samplers.py      离散扩散采样器（D3PM）与能量模型（EBM，未在有限训练下收敛）
  metrics.py       TV / W1 / KL / ESS / 方差等评估指标
  meanfield.py     平均场条件采样器训练与评估工具
  main.py          主线实验脚本：静态精度 + 罕见事件 + 平均场条件采样器
  smoke.py         单元冒烟（模型 + 训练闭环）
  results/         输出表格与图表
```

## 模型设定

经典生灭过程：状态 i = 0..N-1, N=64，速率

- 出生: b(i, mu) = b0 + b1*i + b2*mu
- 死亡: a(i, mu) = a0 + a1*i + a2*mu

静态实验: b2 = a2 = 0。
平均场实验: b2 = a2 = 0.3。

精确不变测度: 经典显式递推（无分布依赖）；线性情形直接对参数 (b, a) 求积。

## 实测结果（main.py 输出）

### 静态精度
样本量 N | MCMC TV | MCMC 墙钟 | Diff TV | Diff 墙钟
5000 | 0.047 | 0.04s | 0.059 | 0.70s
10000 | 0.043 | 0.06s | 0.056 | 1.36s
30000 | 0.017 | 0.17s | 0.052 | 3.88s

静态场景 MCMC 占优（状态空间小、自相关短、Metropolis 提议匹配）。扩散在罕见事件与摊销场景下才显出优势。

### 罕见事件方差缩减（核心结果）
估计 P(i ≥ 40) ≈ 5.0e-4:
- MCMC 估计方差 (20 次重复): 4.33e-6
- 扩散估计方差 (20 次重复): 3.09e-8
- **方差缩减 140.07 倍**

iid 采样在低概率区域无自相关浪费，扩散显著胜出。

### 平均场条件采样器（b2 = a2 = 0.3）
训练 13 个 m_mu 网格点，留出 4 个未见点（m=1, 3, 5, 7）评估:
- 训练用时 17.8s
- 留出 m=5, 7 处 TV ~ 0.24-0.27（中心内插表现稳定）
- 留出 m=1, 3 处 TV ~ 0.32-0.43（接近训练边界退化）

## 已知局限

- 能量基线 EBM 在 64 状态空间上未在有限训练步数下收敛（TV ~ 0.98），扩散成为主采样器；EBM 代码保留作方法对比
- 扩散条件生成器在分布依赖项 b2/a2 较小时表现稳定，极端外推区间精度退化
- 静态精度未超越 MCMC；本项目的定位是"罕见事件与平均场采样"，不是"通用静态采样"

## 与方法论文的关系

- 2-death 过程不变测度的显式递推（用户 SPL 论文，2024）提供无分布依赖情形的精确 ground truth
- 谱隙（用户 JMP 论文指数遍历率）提供分布依赖情形的理论 benchmark
- 条件生成器为平均场自洽迭代提供单步采样原语
