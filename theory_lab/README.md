# Spectral-Gap-Guided Amortized Inference for Distribution-Dependent Birth-Death Processes

物理生成元 Q 是已知的，不变测度 π 是待推断的量。一维链有解析 π，因此只作为可严格验证的 testbed，不用来论证生成模型比直接抽样更快。K 粒子耦合系统的 π 没有闭式解，精确求解的代价随状态数指数增长，那里才是摊销生成有必要性的场景。项目给出三个可证命题、一条物理加权的离散扩散前向核、一套带偏差与置信区间的稀有事件估计，以及全部可复现的实测数字。

## 模型设定

状态 i = 0..N-1，N = 64。经验均值 m 通过饱和函数进入速率

```
phi(m) = m^2 / (kappa^2 + m^2)
birth_i(m) = b0 + b1*i + beta*phi(m)      i -> i+1
death_i(m) = a0 + a1*i + gamma*phi(m)     i -> i-1
```

默认参数 b0 = 1.0, b1 = 0.5, a0 = 0.6, a1 = 1.5, beta = 10.0, gamma = 0.0, kappa = 5.0。a1 > b1 保证正常返。固定 m 时是线性生灭链

```
pi_n(m) = pi_0(m) * prod_{k=0}^{n-1} birth_k(m) / death_{k+1}(m)
F(m) = E_{pi_m}[i]
```

平均场自洽方程是 F(m) = m。反射截断只在 max_m pi_{N-1}(m) < 1e-12 时才被接受，实测 8.7e-17。

## 三个可证命题

**命题 1 混合时间与扩散步数.** 令 w_i = sqrt(birth_i * death_(i+1))，R 是路径图上以 w_i 为边权的对称拉普拉斯。R 对称，所以 uniform 是其平稳测度，exp(t R) 是合法的腐蚀核，且只用 Q 的速率，不用 π。在 L2(uniform) 中

```
TV(q_0 exp(t R), u) <= 0.5 * sqrt(N-1) * exp(-c_R t)
t_final >= log(sqrt(N-1) / (2 eps)) / c_R
```

物理速率还给出 c_R 的可证下界 c_R >= 2 min_i w_i (1 - cos(pi/N))。Q 的 L2(pi) 谱隙 c_Q 与 c_R 由 Weyl 不等式联系，因为 R - S 是对角阵，S = diag(sqrt(pi)) Q diag(1/sqrt(pi))。m = 5.5 处实测 c_R = 0.06558, c_Q = 1.00448, 下界 0.00888 <= c_R, |c_R - c_Q| = 0.93890 <= max|R-S| = 35.4017。Weyl 界宽松但严格成立。两个核在同一混合预算 eps = 1e-3 下校准，T = 40 时物理核终点 TV = 2.19e-4，均匀核 2.48e-4，实测曲线全程不越过理论界。

**命题 2 导数界与误差传播.** 由 pi' Q + pi Q' = 0 得 pi' = -pi Q' Q^#，于是

```
|F'(m)| <= || (pi Q')/pi ||_{2,pi} * || i - F ||_{2,pi} / c_Q
F'(m)  = pi (dQ/dm) g,    Q g = -(i - F),  pi^T g = 0
|m_hat - m*| <= eps / (1 - |F'(m*)|)
```

Poisson 方程解出的 F' 与有限差分相差 2.1e-11。m = 3 时 |F'| = 1.2451 <= 上界 1.3372。扫 beta 得到双稳态窗口 (9.1143, 11.0615)，宽度 1.9473，窗口内侧 |F'| 逼近 1 使 eps/(1-|F'|) 放大到 31.95 倍，这是临界慢化的定量判据。beta = 10 时有三个不动点: 1.1370 (F' = 0.6941, c_Q = 1.1427, 稳定), 2.5481 (F' = 1.2081, 不稳定), 7.0673 (F' = 0.6277, 稳定)。

**命题 3 稀有事件的无偏估计.** 取支集落在 A = {i >= k} 的 proposal q，普通重要性采样估计

```
I_hat = (1/n) sum_j pi(x_j) / q(x_j),   x_j ~ q
```

是无偏的。相对误差满足 RE ≈ sqrt((1 + CV_w^2)/n)，达到相对误差 delta 需要 n >= (1 + CV_w^2)/delta^2。最优指数倾斜尺度由 pilot 样本的权重方差最小化选取，proposal 完全不依赖训练数据的尾部观测。

## 方法

`diffusion.py` 的前向核是 exp(t R)，Pbar[k] = exp(k dt R)，反向步用精确 Bayes 后验

```
q(x_(k-1) | x_k, x_0) = Pstep[k][x_(k-1), x_k] * Pbar[k-1][x_0, x_(k-1)] / Pbar[k][x_0, x_k]
p_theta(x_(k-1) | x_k) = A[k][:, x_k] * ((p_theta(x_0|x_k) / Pbar[k][:, x_k]) @ Pbar[k-1])
```

网络只预测 x_0，反向链不再注入均匀噪声，半群性 Pbar[k-1] Pstep[k] = Pbar[k] 保证后验自动归一化。对照的均匀核 D3PM 用相同的反向公式，唯一差别是前向核有没有编码物理速率。条件输入是归一化后的 m，物理核随 m 变化，均匀核不随 m 变化。

`inference.py` 用学习到的条件生成器替代 F(m) 做随机不动点迭代，最后 5 次迭代做 Polyak 平均。`coupled.py` 的自回归生成器 p_theta(x_1..x_K | beta) = prod_j p_theta(x_j | x_<j, beta) 给出 iid 联合样本，联合 π 由 Nc^K x Nc^K 线性系统数值求解并报告残差。

## 实测结果

CPU 单机，seed = 0，全量运行 220.4s。所有数字来自 `results/summary.json`。

**条件生成，3 个未见 m，每点 3 个随机种子，每点 10000 样本.** 两个模型共用同一训练集 (39000 个连续时间样本)、同一网络、同一 2500 步与学习率，唯一变量是前向核。

| m | 物理核 TV (95% CI) | 均匀核 TV | 物理核 W1 | 均匀核 W1 |
|---|---|---|---|---|
| 1.5 | 0.0420 [0.042, 0.043] | 0.0983 | 0.052 | 0.114 |
| 5.5 | 0.0465 [0.046, 0.048] | 0.0517 | 0.206 | 0.119 |
| 9.5 | 0.0308 [0.028, 0.033] | 0.0534 | 0.051 | 0.217 |

平均 TV 从 0.0678 降到 0.0398，降低 41.3%。W1 在 m = 5.5 处物理核反而更差，NLL 两者接近，去噪 CE 物理核更高，这些都不做修饰。

**m = 5.5 处的基线.** oracle iid 0.0125, 训练直方图 iid 0.0122, 连续时间 Gillespie 0.0139, 修复的 EBM 0.0122, 旧 thin = 4 Metropolis 0.0186 (ESS 1019/10000), 旧 D3PM 0.1469。一维 testbed 上直接方法仍然更准，扩散的价值是条件泛化和物理归纳偏置，不是静态采样精度。

**摊销自洽.** 条件均值误差的 3 sigma 经验上界 eps = 0.3003。从 m0 = 0.5 出发收敛到 1.2906，精确低态 1.1370，误差 0.1536 <= 理论上界 0.9817。从 m0 = 12.0 出发收敛到 6.8154，精确高态 7.0673，误差 0.2519 <= 上界 0.8065。两个不同吸引盆被正确区分，误差传播界在两次实验中都成立。

**稀有事件.** 取 m* = 7.0673, k = 30, p_A = 1.73505e-6。30000 个训练样本里 i >= 30 命中 0 次，proposal 不含任何训练数据信息。最优倾斜尺度 1.5，权重 CV^2 = 0.01022。普通 IS 的 MSE = 1.65e-17，比 crude iid 的经验 MSE 2.50e-9 低 1.51e8 倍。达到 5% 相对误差 IS 需要 404 个样本，crude 需要 2.31e8 个。

**耦合粒子系统.** K = 2, Nc = 24, 576 个状态，数值 π 的残差 4.7e-16。自回归生成器对整体分布 TV = 0.0352, W1 = 1.383。阈值 (x1+x2)/2 >= 15 处 p = 4.023e-3，生成器给出 3.980e-3，相对误差 1.08%。精确推断耗时从 64 状态的 0.002s 增长到 4096 状态的 1.285s，状态数增 64 倍而耗时增约 640 倍，稠密 LU 的理论复杂度是 O(M^3)，小矩阵区受固定开销主导。

## 定位与边界

一维 64 状态上 oracle iid 与直方图 iid 的 TV 约 0.012，优于扩散的 0.0398。摊销自洽耗时 20.74s，每次重新跑 Gillespie 只需 0.47s，慢 43.7 倍。这两个数字是如实报告的负面结果，本项目不主张在小状态空间上省时。摊销的必要性只由耦合系统的状态空间爆炸曲线支撑。

双稳态窗口只有 1.95 宽，结论对 beta 敏感。IS 需要能逐点计算目标密度，在 K >= 3 时只能换成数值或模拟近似。耦合实验只做了 K = 2，K >= 3 未实跑。Weyl 界虽然严格，但比实际谱隙差宽松得多。每个子实验使用独立的固定随机流，--seed 只改变主随机流，所以两次运行里稀有事件等子实验数值相同。其余结论在 seed = 7 且训练步数减到 40% 时仍然成立，物理核的平均 TV 从 0.0398 变为 0.0335，均匀核从 0.0678 变为 0.0718，所有理论上界依旧成立。所有指标是 CPU 单机单次全量运行加一次独立复现，不是大规模重复实验。

## 复现

```
pip install -r requirements.txt
python tests.py -v
python experiments.py
python experiments.py --seed 7 --scale 0.4 --out results_replication
```

`experiments.py` 把全部表格、图和 `summary.json` 写到 `results/`，输出目录基于脚本位置，可复现实验用 `--out` 写到独立目录。无 SciPy 依赖，矩阵指数用 scaling-and-squaring Taylor 实现。
